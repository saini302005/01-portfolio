# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, education, and contact information.

## 👨‍💻 About

Hi, I'm **Sanju Saini**, a B.Tech student specializing in **Artificial Intelligence and Machine Learning**.

I am learning Web Development, Artificial Intelligence, and Machine Learning by building practical real-world projects.

## 🚀 Features

* Responsive personal portfolio
* Home, About, Skills, Projects, Education and Contact sections
* Typing text animation
* Dark / Light mode
* Theme preference saved using localStorage
* Contact form validation
* Scroll reveal animations
* Mobile-friendly hamburger menu
* Responsive project and skill cards
* Smooth scrolling navigation

## 🛠️ Technologies Used

* JavaScript
* Git

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/saini302005/01-portfolio.git
```

### 2. Open the project

```bash
cd 01-portfolio
```

### 3. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for easier development.
